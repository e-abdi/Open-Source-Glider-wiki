Strobe light
++++++++++++++++

Useful for locating the glider, especially in the dark. It is important to be able to control exactly when it turns on, because otherwise it could attract unwanted attention and make the glider more vulnerable.
SeaExplorer and OceanScout both have nice strobe solutions built into the antenna. Slocum has a small one next to its antenna. Seaglider does not come with a strobe, so you need to install your own if you need one.

    :width: 400


Implementation in Tuba
=================================

For Tuba, one option would be to try the `Blue Robotics Nav Light <https://bluerobotics.com/store/boat/blueboat-components-spares/navlight/>`__ or simply pot a similar LED arrangement inside the antenna mast.
