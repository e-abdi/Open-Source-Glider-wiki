Strobe light
++++++++++++++++

Useful for locating the glider, especially when it is dark. It is important to be able to control exactly when it comes on, because otherwise it could attract unwanted attention and ultimately make the glider more vulnerable.
SeaExplorer and OceanScout both have a nice strobe solution built into the antenna. Slocum has a small one next to its antenna. Seaglider does not come with a strobe, so you need to install your own if you need one.
